# Winstrap Privacy Policy

Winstrap is an open-source best Bootstrapper (**Fork of Bloxstrap** on Version 2.9.1)

### 1. Data Collection
Winstrap **does not collect, store, or transmit** any personal data, Roblox credentials, passwords, cookies, or telemetry to external servers. 

### 2. Local Storage
All user preferences, configuration files, and FastFlags are stored exclusively locally on your device (typically within the `%localappdata%\Winstrap` directory).

### 3. Third-Party Services
* **Discord Rich Presence:** If enabled, Winstrap communicates locally with the Discord client on your machine solely to display your current game session status. No personal data is sent to Discord's servers by Winstrap itself.
* **Roblox Corporation:** Winstrap interacts exclusively with official Roblox servers to download and update game files, functioning identically to the standard Roblox launcher in this regard.

### 4. Contact
If you have any questions regarding this Privacy Policy, *please open an Issue in our official GitHub repository!*
